# 1 ใน 66 ล้าน — เกมจำลองชีวิตคนไทยบนดาวอาสตร้า

เกมจำลองชีวิตคนหนึ่งคน ตั้งแต่เกิดจนตาย บนโลกสมมติ "ดาวอาสตร้า" — แต่ตัวเลขสถิติที่อ้างอิงในกล่องแต่ละใบ
เป็นข้อมูลจริงของประเทศไทย (NHES7 / ข้อมูลสุขภาพ 43 แฟ้ม / National Statistical Office) มีแหล่งที่มากำกับทุกค่า

▶️ **เล่นเลย:** https://nrok47.github.io/thai-life-sim/

---

## ⚠️ อ่านก่อนเล่น

เหตุการณ์ สถานที่ และตัวละครทั้งหมดในเกมนี้เป็น **เรื่องสมมติ** บนดาวอาสตร้า
ชื่อจังหวัด/ตำบล ตั้งให้คล้ายชื่อจริงโดยจงใจเพื่อให้รู้สึกใกล้ตัว แต่ **ไม่มีอยู่จริง** และไม่ได้หมายถึงพื้นที่ใดในประเทศไทย
ส่วนตัวเลขสถิติระดับประเทศ/ระดับภาคในกล่องอ้างอิง เป็นข้อมูลจริง มีแหล่งที่มากำกับทุกค่า และสายด่วน/สิทธิการรักษาที่ปรากฏเป็นของจริงที่ติดต่อได้

ค่าที่ยังหาที่มาไม่ได้ จะติดป้ายเหลือง **"ยังไม่ยืนยัน"** ให้เห็นชัดเจน — **ไม่ใช่เครื่องมือพยากรณ์หรือเครื่องมือทางการแพทย์**

---

## วิธีเล่น

กด "เริ่มชีวิต" → เกมสุ่มตัวละคร (เพศ/พื้นที่/ฐานะครอบครัว) ให้ดูก่อนหนึ่งหน้า แล้วกด "เริ่มใช้ชีวิต"
ชีวิตเดินไปเรื่อย ๆ ตามความเร็วที่เลือก (หยุด–16×) จะมีการ์ด "ทางแยกของชีวิต" เด้งขึ้นเป็นระยะให้เลือกทาง
แต่ละใบมีกล่องสถิติอ้างอิงกำกับ และถ้าเป็นเรื่องที่หนักใจ (สุขภาพจิต/ความรุนแรง/อุบัติเหตุ) จะมีสายด่วนจริงติดไว้เสมอ

| ส่วน | ทำอะไร |
|---|---|
| ความเร็วเวลา | หยุด / 1× / 2× / 4× / 8× / 16× |
| จุดเน้นรายปี | เลือกให้น้ำหนักไปทาง สุขภาพ/ครอบครัว/งาน/ความรู้ |
| ให้ตัดสินใจอัตโนมัติ | เลือกทางที่ดีต่อสถานะรวมให้เอง เล่นจบได้ไวขึ้น |
| บันทึกชีวิต | ไล่ดูเหตุการณ์ทุกปีย้อนหลังได้ |

จบเกมเมื่อเสียชีวิตตามความเสี่ยงของตารางชีพ (ปรับตามสุขภาพ/สิ่งแวดล้อม/ฐานะ) — กดคัดลอกข้อความสรุปชีวิตเพื่อแชร์ได้

## แก้ไขต่อเอง

```
index.html   ← โครงหน้า + สไตล์ทั้งหมด (ไม่มี build step)
game.js      ← เอนจินเกม การคำนวณ การแสดงผล
data.js      ← ข้อมูลเหตุการณ์/สถิติ/โลกสมมติ — สร้างอัตโนมัติจากต้นฉบับ ห้ามแก้ไฟล์นี้ตรง ๆ
```

ไม่ใช้ไลบรารีภายนอก ไม่มี build step — เปิด `index.html` ได้เลย (หรือรันผ่าน local server เพื่อเลี่ยงข้อจำกัดบางเบราว์เซอร์)
การสุ่มทั้งหมดผูกกับ seed จึงเล่นซ้ำด้วยเลขเดิมแล้วได้ผลเดิมทุกครั้ง
